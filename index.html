Features
一个命令启动，完整 AI 工作台

终端变日志面板，浏览器变聊天界面。多个 Agent 在群聊中协作。

Core

Built-in Gateway

启动即开网关（默认 :8765），浏览器打开即用。流式逐字输出、代码高亮、命令实时执行反馈。

Core

Multi-Agent

任意数量命名 Agent，各自独立人设、对话历史。支持 OpenAI、DeepSeek、Claude、Ollama 等任意兼容接口。

Chat

Group Chat & @mention

多 Agent 群聊，@name 定向发言，@all 全员讨论。AI 回复中 @其他 Agent 自动触发链式召唤。

Engine

Command Engine

AI 嵌入 22+ 命令（//exec //write //read //python 等），自动执行回传结果继续对话。危险命令自动拦截。

UI

Web UI Console

内置命令台直接执行服务器命令，实时日志面板监控所有请求和事件。支持 Agent/Group GUI 管理。

UI

Terminal Dashboard

终端自动变实时日志：连接状态、请求路由、命令执行追踪。/log 控制级别，0=关闭 1=常规 2=详细。
